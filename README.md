# Unframed Art Showcase

Build a modern full-stack frontend for an art-sharing social platform called "Unframed".

Tech:

- React

- TypeScript

- Tailwind CSS

- Modern component-based architecture

Unframed is a platform where artists can showcase their artwork, discover other artists, follow them, like artwork, comment, search artwork, and manage their own profile.

Design direction:

- Premium artistic portfolio aesthetic

- Minimal but visually rich

- Editorial/gallery-inspired layout

- Lots of whitespace

- Large artwork imagery

- Elegant typography

- Warm neutral background

- Subtle borders and shadows

- Smooth hover transitions

- Responsive on desktop, tablet and mobile

Pages:

1. Landing page

2. Login

3. Register

4. Home/feed

5. Artwork detail

6. Artist profile

7. Create artwork

8. Edit profile

Feed:

- Navigation bar

- Search bar

- Artwork cards in a beautiful gallery/masonry-style layout

- Artist name

- Artwork title

- Like button and like count

- Comment button

- Clicking artwork opens artwork detail

Artwork detail:

- Large artwork

- Title

- Description

- Artist information

- Like button

- Comments section

Artist profile:

- Profile image

- Name

- Bio

- Follow button

- Artwork gallery

Create artwork:

- Title

- Description

- Image URL

- Submit button

Edit profile:

- Name

- Bio

- Profile image URL

Use realistic placeholder artwork images for the initial UI.

Do NOT implement a fake backend or fake authentication.

Keep the API integration layer clearly separated so it can connect to an external Spring Boot REST API later.
